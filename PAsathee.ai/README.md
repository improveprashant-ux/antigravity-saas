# PAsathee.ai Landing Page

## Overview
This is a modern, responsive landing page for PAsathee.ai - an AI-powered personal assistant service.

## Files
- `index.html` - The complete landing page

## Features Included
1. **Hero Section** - Eye-catching headline with gradient effects and floating animations
2. **Features Section** - 6 key features with icons and descriptions
3. **How It Works** - 3-step process to get started
4. **Pricing Section** - 3 tiers: Free, Pro ($19/mo), Enterprise ($99/mo)
5. **Testimonials** - Customer reviews from Sarah Johnson, Michael Chen, Emily Davis
6. **CTA Section** - Call to action for signup
7. **Footer** - Navigation links and company info

## Design
- Dark gradient background (#0f172a to #1e1b4b)
- Purple/Cyan accent colors (Tailwind custom config)
- Glassmorphism effects (backdrop blur, semi-transparent cards)
- Animated floating elements and pulsing glows
- Responsive design for all screen sizes
- Tailwind CSS via CDN

## Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Google Fonts (Inter)
- Vanilla JavaScript (minimal, for animations)

## How to Use
Simply open `index.html` in any modern web browser.
